# 量子—经典混合方法与代码适配名录

本页整理方法名称、别名、谱系、输入条件、公开来源及代码适配边界，不含私有队列统计、训练成绩或运行产物。机器可读版本见[algorithm_catalog.json](../../configs/public/algorithm_catalog.json)。

目录有**68条记录**，包括家族、命名变体、应用适配、经典控制和算法组件；关联**48个代码配置ID**。这不是相同数量的独立量子算法，也不是穷尽全部已发表方法或完成原文精确复现的声明。

公开文献和官方实现是方法来源；代码关联表示这里有相应适配，不是该上游实现的端到端复现。实验验证、原始数据和性能报告不随此公开版本发布。

## 计数与实现边界

- PQC、VQC和QNN常是重叠术语；别名不重复计成独立家族。编码、纠缠拓扑、损失或读出变化可形成配置，但应说明共同谱系。
- PennyLane、CUDA-Q和PyTorch是软件工具；CPU/GPU、求导方式、shots、噪声和优化器不是新增学习算法。
- “缺少参考实现”与“已有适配”可以同时成立。目录保留这一差别，不把名称相近的线路称为原论文精确复现。
- QAOA、VQE、QPCA等通常是算法组件或需要特定访问模型；不能只凭名称直接视作普通表格分类器。
- 完整研究使用边界见[标签、分组、特征与模拟限制](research_boundaries.md)。
